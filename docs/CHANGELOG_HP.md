## 2026-05-15 - 出張費距離ベース・基本料金再整理

### 変更内容
- 出発基準を「下関市中心部周辺」に統一。
- 出張費を片道30km以内無料、片道30km超〜90km以内は超過1kmあたり110円へ整理し、所要時間による加算は使わない方針に変更。
- 旧広域区分を使わず、料金ページとシミュレーターの出張費表示を距離で判断できる形に変更。
- 家具組立・簡単な軽作業を3,300円〜 / 1時間に変更し、生活まわりの簡単な代行を3,300円〜 / 1時間で追加。
- 小荷物の運搬・荷物移動は距離・荷物量・作業時間により変わるため別途見積もり扱いに変更。
- 供花・お線香セットを4,400円〜に変更し、購入品手配・精算手数料を1,100円〜に整理。
- 買い物・購入品がある場合は、原則として作業料と購入予定額を事前に預かり、購入後にレシート等を写真で報告して差額精算する説明を追加。
- 継続利用割引は2回目以降、1回あたり1,000円引きの目安に統一。
