# QA チェックリスト

## 1. フォーム送信テスト
- [ ] 依頼フォーム：必須項目を空で送信できないこと。
- [ ] 依頼フォーム：同意チェックを入れないと送信できないこと。
- [ ] 依頼フォーム：送信後、`/thanks.html?type=request` に遷移すること。
- [ ] パートナーフォーム：送信後、`/thanks.html?type=partner` に遷移すること。
- [ ] パートナーフォーム送信後、サンクスページにLINE誘導ボタンが表示されること。
- [ ] スパム対策：3秒以内の連続送信がブロックされること。
- [ ] スパム対策：隠しフィールド（website）に入力すると送信が中断されること。

## 2. 料金シミュレーターテスト
- [ ] パック料金の切り替えで合計金額が正しく変動すること。
- [ ] 距離(km)の入力で `距離 × 50円` が正しく加算されること。
- [ ] 緊急料金（通常/翌日/当日）の切り替えが正しく反映されること。
- [ ] オプションのチェックON/OFFが正しく反映されること。

## 3. バックエンド（GAS）テスト
- [ ] フォーム送信後、スプレッドシートの `Requests` または `Partners` タブに正しく行が追加されること。
- [ ] 管理者メールアドレス宛に通知メールが届くこと。
- [ ] （LINEトークン設定時）LINEに通知メッセージが届くこと。

## 4. UI/UX・法務確認
- [ ] スマホ表示でレイアウト崩れがないこと。
- [ ] ヘッダーのリンクが正しく機能すること。
- [ ] 利用規約に「身体介助・医療行為・危険作業・不法侵入の禁止」が明記されていること。
- [ ] 料金が「報告の厚み」で決まる旨が明記されていること。
