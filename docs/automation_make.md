# Make.com 自動化ロードマップ（将来実装用）

初期は手動運用（GAS + スプレッドシート）で回し、件数が増えた段階で Make.com を導入して自動化を進めます。

## 1. 依頼受付〜タスク管理の自動化
**トリガー**: GAS Webhook（依頼フォーム送信時）
**アクション**:
1. Google Sheets `Requests` に行追加。
2. Notion または Trello に新規タスクカードを作成（ステータス：新規受付）。
3. Slack または Chatwork に通知（運営チーム共有用）。
4. 依頼主へ自動返信メール（見積内訳・振込先案内）を送信。

## 2. パートナー手配の半自動化
**トリガー**: Notion/Trello のステータスが「入金済」に変更された時
**アクション**:
1. Google Sheets `Partners` から該当エリアの稼働可能パートナーを検索。
2. LINE Messaging API を経由して、条件に合うパートナーへ一斉または順次打診メッセージを送信。
3. パートナーからの「対応可能」返信（LINE Bot）を受け取り、先着順で割当確定。
4. Google Sheets `Assignments` に行追加。

## 3. 報告受領〜一次検収の自動化（AI活用）
**トリガー**: パートナーからのLINE報告（画像・動画・テキスト）受信時
**アクション**:
1. 画像・動画を Google Drive の専用フォルダへ自動保存。
2. OpenAI API (GPT-4o 等) を呼び出し、画像解析による一次検収を実施。
   - 指定枚数に達しているか？
   - 不適切な写り込み（他人の顔、表札等）がないか？
3. 検収OKの場合：
   - 依頼主へ「納品のご報告」メールを自動送信。
   - Notion/Trello のステータスを「完了」に変更。
4. 検収NGの場合：
   - パートナーへLINEで再提出を促すメッセージを自動送信。

## 4. 会計・支払い処理の自動化
**トリガー**: 毎月15日・末日のスケジュール実行
**アクション**:
1. Google Sheets `Assignments` から、期間内の「検収OK」案件を集計。
2. パートナーごとの報酬額を算出。
3. freee や MoneyForward などの会計ソフトAPIを呼び出し、支払明細ドラフトを作成。
4. パートナーへ「支払い予定通知」をLINE/メールで自動送信。
