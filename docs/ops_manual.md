# 運用手順マニュアル（最初の1件を回す）

## 1. 依頼受付〜見積提示
1. GASから「新規依頼」の通知（メール/LINE）を受信。
2. スプレッドシート `Requests` タブを確認。
3. 依頼内容が利用規約（介護・医療・危険作業・不法侵入等）に抵触しないか確認。
4. 距離(km)が未入力の場合、Googleマップで出発想定地〜目的地を算出し、出張費を確定。
5. 依頼主へ「見積内訳＋振込先＋支払期限」をメール送信（`ops_templates.md` 参照）。

## 2. 入金確認〜パートナー手配
1. 銀行口座の入金を確認。
2. スプレッドシート `Requests` のステータスを「入金済」に変更。
3. スプレッドシート `Partners` から該当エリアのパートナーを検索。
4. パートナーへLINE等で打診（日時・報酬額・作業内容）。
5. パートナー確定後、`Assignments` タブに追記。

## 3. 実施〜報告（一次検収）
1. パートナーが現地で作業実施。
2. パートナーから証跡（写真・動画・チェックリスト）をLINE等で受領。
3. 運営（たけ）が一次検収。
   - 写真の枚数・動画の秒数はパック条件を満たしているか？
   - 不適切な写り込み（他人のプライバシー等）はないか？
4. NGの場合はパートナーへ再提出・再確認を指示。

## 4. 納品〜完了
1. 検収OKの証跡をGoogleドライブの専用フォルダ（依頼主共有用）に格納。
2. 依頼主へ「納品のご報告」メールを送信（URL記載）。
3. スプレッドシート `Requests` のステータスを「完了」に変更。

## 5. パートナーへの支払い
1. 毎月15日・末日締めで、完了案件の報酬を集計（`Payments` タブ）。
2. パートナーへ「支払い予定通知」を送信。
3. 指定口座へ振込実行。
