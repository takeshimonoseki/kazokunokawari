## リスク
- 個人情報の取り扱い: GDPRや個人情報保護法など、適切な個人情報保護対策の実施。
- 誤送信: 不適切な宛先へのメール通知やデータ送信のリスク。
- GAS URL漏れ: 公開リポジトリやHTMLにGAS Web AppのURLがハードコードされ、悪用されるリスク。
- スプレッドシートID漏れ: Google Sheets IDが漏洩し、意図しないアクセスや改ざんのリスク。
- 通知失敗: メールやLINEによる管理者への通知が失敗し、問い合わせ対応が遅れるリスク。
- 二重送信: ユーザーが意図せず同じ内容を複数回送信してしまうリスク。
- テストデータと本番データ混在: テストフェーズで生成されたデータが本番運用時に混入するリスク。
- 料金表示と正式見積もりのズレ: シミュレーターの概算と正式見積もりの間に大きな乖離が生じ、ユーザーの不信感を招くリスク。
